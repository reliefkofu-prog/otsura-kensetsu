# Deployment Guide

This project is ready to be deployed. The local repository has been initialized and committed.

## 1. Push to GitHub

Run the following command in your terminal to push the code to your GitHub repository:

```bash
git push -u origin main
```

*Note: If the remote repository `reliefkofu-prog/otsura-kensetsu` is not empty, you might need to pull first or force push.*

## 2. Deploy on Vercel

1.  Log in to [Vercel](https://vercel.com/login).
2.  Click **"Add New..."** -> **"Project"**.
3.  Import the repository `otsura-kensetsu` (or `reliefkofu-prog/otsura-kensetsu`).
4.  **Framework Preset**: Select **"Other"** (since this is a plain HTML/CSS static site).
5.  Click **"Deploy"**.

Your website will be live at a Vercel URL shortly!
